# AI-VIRTUAL-PAINTER
AI Virtual Painter (ART VISION) is a fun and interactive computer vision project that lets you draw using hand gestures, with no need for a mouse or touch screen. Built with OpenCV and MediaPipe, it tracks your fingers in real-time, allowing you to choose tools like brush (with color options), eraser, and clear screen.

🔧 Features:
Hand gesture-based drawing
Real-time finger tracking
Tool selection using gesture icons
Color palette and eraser options

📌 Technologies Used:
Python
OpenCV
MediaPipe
